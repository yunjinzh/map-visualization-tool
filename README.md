# Map Visualization Tool

A modern interactive map dashboard built with Vite, React, Leaflet, and ECharts.

## Features
- Interactive geospatial map with selectable markers
- Category filters for different site types
- KPI summary cards and region comparison chart
- Responsive dashboard layout for desktop and mobile

## Tech Stack
- React + TypeScript
- Vite
- Leaflet + react-leaflet
- ECharts
- Lucide icons

## Run locally
```bash
npm install
npm run dev
```

Then open http://localhost:5173.

## Build
```bash
npm run build
```
